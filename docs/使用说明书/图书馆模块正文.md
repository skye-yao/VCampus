# 5.4 图书馆

图书馆模块为师生提供图书检索、详情查看、预约、借阅记录查询、图书评价、挂失、费用缴纳以及电子书预览和下载等服务。具有图书馆管理权限的管理员还可维护馆藏信息、查询业务名单，并在核对实体图书和借阅人后办理借书、还书及退款。

用户登录系统后，从主界面进入“图书馆”。页面包含“图书检索”“我的图书馆”“罚款缴费”“公共挂失公告”和“图书管理”页签；“图书管理”仅供具有相应权限的管理员使用。点击左上角“← 返回”可回到系统主界面。

5.4.1 图书检索

（1）打开“图书检索”页签，在搜索框输入书名、作者或 ISBN。

（2）点击“搜索”或按回车键，查看符合条件的图书。检索结果显示编号、书名、作者、ISBN 和状态。

（3）需要重新浏览馆藏时，点击“显示全部”。选择一行图书后，可继续查看详情、预约或评价。

【截图位置 图5.4-1 图书检索界面】使用师生账号，在搜索框输入一个能查到图书的关键词；保留搜索框、搜索结果及状态列。

5.4.2 查看图书详情

（1）在检索结果列表中单击目标图书。

（2）在右侧“图书详情与评价”区域查看书名、作者、出版社、ISBN 和状态。

（3）点击“展开详情”查看完整信息及图书编号；点击“收起详情”可折叠显示。

【截图位置 图5.4-2 图书详情界面】选中一本信息完整的图书并点击“展开详情”，同时保留左侧选中行和右侧详情。

5.4.3 预约图书与取消预约

（1）在“图书检索”中选中状态为“可借”的图书，点击“预约选中图书”。

（2）预约成功后，查看系统提示，并在预约后12小时内到图书馆找管理员办理取书；超过取书时限，预约将自动取消。

（3）进入“我的图书馆”，在“预约记录”中查看预约时间和状态。

（4）不再需要借阅时，选中仍处于预约中的记录，点击“取消选中预约”，在确认框中确认取消。

预约成功表示图书已被预留，实际借出须由管理员现场核对后办理。若图书已被借出、预约或处于其他不可预约状态，系统会提示暂不可预约。

【截图位置 图5.4-3 预约成功提示】选中可借图书并预约，截取包含“12小时内”取书提示的成功弹窗。

【截图位置 图5.4-4 预约记录与取消预约】打开“我的图书馆”，选中一条有效预约，截取预约记录和“取消选中预约”按钮。

5.4.4 我的图书馆

（1）切换到“我的图书馆”页签。

（2）在“当前借阅”查看正在借阅的图书、借阅时间、应还时间和状态；归还实体图书时，到图书馆由管理员办理。

（3）在“借阅历史”查看以往借阅及归还情况；在“预约记录”查看预约的处理状态。

（4）办理借还、挂失或取消预约后，可点击“刷新”获取最新记录。

借阅期限为14天，应还时间以当前借阅记录为准。图书评价在“图书检索”右侧操作，费用信息在“罚款缴费”页签查看。

【截图位置 图5.4-5 我的图书馆界面】准备含当前借阅、借阅历史和预约记录的师生账号，截取三个区域及顶部操作按钮。

5.4.5 图书评价

（1）在“图书检索”中选择要评价的图书，右侧列表将显示该书已有评价。

（2）在“写下你的评价……”输入框中填写内容，点击“发表评价”。内容不能为空。

（3）发表成功后，在评价列表中查看新增内容。

（4）需要删除自己的评价时，选中该条评价，点击“删除选中评价”。普通用户只能删除本人发表的评价。

【截图位置 图5.4-6 图书评价界面】选中一本已有评价的图书，截取书名、评价列表、输入框和发表及删除按钮。

5.4.6 图书挂失与解除挂失

（1）图书遗失后，进入“我的图书馆”，在“当前借阅”中选中对应图书。

（2）点击“挂失选中图书”，系统提示成功后刷新，检查该借阅记录的挂失状态。

（3）找回图书且本次借阅尚未结清时，选中对应借阅记录，点击“解除挂失”。也可将实体图书交给管理员办理归还。

挂失仅针对本人当前借阅的图书。挂失时冻结逾期费用，并按图书价格计算遗失赔偿。已缴清赔偿后，本次借阅结束；之后找回图书，应联系管理员办理入库及退款。

【截图位置 图5.4-7 图书挂失状态】完成一次挂失后，截取“当前借阅”中显示挂失状态的记录及“解除挂失”按钮。

5.4.7 罚款查询与缴费

（1）进入“罚款缴费”页签，查看待结算费用和费用记录列表。

（2）选中一条记录，在下方核对逾期费、赔偿价、实付金额、已退款金额和费用原因。

（3）对可缴费记录点击“校园银行缴费”，核对支付窗口中的金额，输入6位校园银行支付密码并确认。

（4）收到缴费成功提示后，刷新检查记录状态；可到校园银行交易流水中核对扣款。

逾期费用按每天0.5元计算，不足一天按一天计。普通逾期借阅须先归还图书，再结算费用；挂失可通过赔偿结清。无需缴费、借阅尚未结束或挂失图书尚未录入价格时，系统可能提示暂不能缴费。若支付失败，按提示检查支付密码和账户余额。

【截图位置 图5.4-8 费用明细】选中一条有费用的记录，保留待结算总额、记录状态及下方明细。

【截图位置 图5.4-9 校园银行支付窗口】点击一条可缴费记录的“校园银行缴费”，截取金额和密码输入框，密码保持空白。

5.4.8 电子书在线预览与下载

（1）在“图书检索”中选中需要阅读的图书。

（2）点击“在线预览”，等待系统获取电子书并打开预览窗口。

（3）需要保存时，点击“下载图书”，在“保存电子书”窗口选择保存目录及文件名，确认保存。

（4）看到“下载完成”提示后，可在所选目录找到 PDF 文件。若提示获取失败，请检查连接或联系管理员确认该书的电子资源。

电子书支持 PDF 格式，能否读取取决于该图书是否已配置可用的电子资源。

【截图位置 图5.4-10 电子书预览】选择已配置 PDF 的图书，打开“在线预览”，截取书名及可阅读的正文页面。

【截图位置 图5.4-11 电子书下载完成】完成一次下载后，截取下载完成提示；保存路径可使用专门的演示文件夹。

5.4.9 公共挂失公告

（1）进入“公共挂失公告”页签，点击“刷新挂失公告”。

（2）查看公告中的书名、图书编号、作者及挂失时间。

（3）发现遗失图书时，将图书交至图书馆服务台。解除挂失后，对应公告自动撤下。

【截图位置 图5.4-12 公共挂失公告】在系统存在有效挂失记录时刷新公告，截取公告内容和服务台提示。

5.4.10 管理员维护图书信息

使用具有图书馆管理权限的管理员账号登录，进入“图书管理”页签。左侧为馆藏列表，右侧为图书信息表单。

（1）新增图书：点击“清空表单”，填写 ISBN、书名、作者，可补充出版社及图书价格，状态设为“可借”，点击“新增上架”。图书编号由系统自动生成，编号不连续属于正常情况。

（2）修改信息：在列表中选中图书，核对右侧信息，修改后点击“保存修改”。借出前必须录入有效图书价格，用于遗失赔偿；价格须为大于0且最多两位小数的金额。

（3）查询状态：选中图书，点击“查询状态”，查看当前状态提示。

（4）找回入库：对处于“遗失”状态且已找回的图书，将状态改为“可借”并保存。借阅、预约和挂失状态应通过对应业务操作更新。

（5）下架图书：核对选中的图书后点击“下架图书”。若该书有关联业务记录导致下架失败，应根据系统提示核实记录。

【截图位置 图5.4-13 管理员图书管理界面】使用有图书馆权限的管理员账号，选中一本图书，截取馆藏列表、完整表单及各操作按钮，必要时滚动右侧表单。

5.4.11 管理员查询业务名单

（1）在“图书管理”中点击“业务名单”。

（2）在名单类型中选择“借阅名单”“罚款缴费名单”“挂失名单”或“预约名单”。

（3）在筛选框输入账号、姓名、书名或状态查找记录；点击“刷新名单”获取最新数据。

【截图位置 图5.4-14 图书馆业务名单】打开“业务名单”，选择有数据的名单类型，保留类型选择框、筛选框和记录表格。

5.4.12 管理员办理借书与还书

（1）在“图书管理”中点击“借还与缴费”，打开“借还与缴费管理”窗口。

（2）办理借书：进入“预约待借”，按账号、姓名或书名查找有效预约，核对到场借阅人和实体图书，并确认未超过取书截止时间。选中记录，点击“确认借书”，在确认弹窗中再次核对并确认。

（3）办理还书：进入“借阅未还”，收到实体图书后选择对应记录，点击“确认还书”，核对信息并确认。找回的挂失图书也可在此归还。

（4）成功后点击“刷新列表”检查最新结果，并提醒读者在“我的图书馆”刷新；有逾期费用时，可先还书，再由读者缴费。

【截图位置 图5.4-15 管理员确认借书】打开“预约待借”，选中一条有效预约，截取借阅人、书名、取书截止时间及“确认借书”按钮。

【截图位置 图5.4-16 管理员确认还书】打开“借阅未还”，选中一条借阅记录，截取应还时间、记录详情及“确认还书”按钮。

5.4.13 管理员办理退款

（1）在“借还与缴费管理”中切换到“罚款与退款”。

（2）选择有可退金额的记录，核对账号、姓名、实付金额、已退款金额及可退金额，点击“办理退款”。

（3）在退款窗口输入退款金额、当前管理员用户名和登录密码。退款金额必须大于0、最多两位小数，且不超过可退金额。

（4）点击“确认退款”。款项退回原账单所属用户的校园银行账户，收款账号不可自行修改。成功后刷新列表检查退款结果。

【截图位置 图5.4-17 管理员退款窗口】选中有可退余额的账单并点击“办理退款”，截取绑定账号、可退金额和表单；管理员密码保持空白。
