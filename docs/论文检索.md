# 图书馆论文检索

图书馆新增“论文检索”标签页，直接从客户端访问 arXiv 官方公开接口，无需数据库变更或 API 密钥。学生、教师及管理员均可使用。

## 使用

1. 输入英文关键词，例如 `machine learning`，按 Enter 或点击“检索论文”。多词按 AND 检索。
2. 选择相关度或最新发表排序，然后重新检索。每页 10 条，最多浏览前 100 页。
3. 选中论文，查看作者、日期、学科、arXiv 编号及摘要。
4. “内部阅读”获取 PDF 并复用现有阅读窗口，支持滚动和页码跳转。
5. “下载全文”选择保存位置；“浏览器打开”直接打开 PDF；“原文页面”打开 arXiv 摘要页。
6. API 超时或限流时，可使用搜索栏旁的“网页检索”在浏览器中打开当前关键词的官方搜索页面；网页结果不会自动导入客户端。

收到 HTTP 429 后程序至少冷却 60 秒，并尊重服务器更长的 Retry-After 等待时间。这是客户端最短等待时间，不代表接口一定在一分钟内恢复。冷却期间不再次发送检索请求，已缓存的成功查询仍可使用。

## 网络与边界

### 浏览器能访问，客户端连接超时

浏览器或 VPN 的访问路径不一定由 Java 自动使用。论文模块支持单独配置代理：将 `config/paper-network.properties.example` 复制为工作目录下的 `config/paper-network.properties`，按 VPN 实际 HTTP/mixed 端口填写：

```properties
proxy.type=http
proxy.host=127.0.0.1
proxy.port=7890
```

此配置只影响论文检索和 PDF 获取，不影响校园服务器连接。文件已被 Git 忽略，不把个人代理配置提交到仓库。修改后下一次网络请求生效；Clash 必须运行，端口必须与其实际配置一致。可用 `proxy.type=direct` 明确直连，或 `system` 使用 Java 默认代理选择。没有文件时保持默认行为。

配置路径可用 JVM 参数 `-Dvcampus.paper.config=绝对路径` 指定。运行打包客户端时工作目录通常是启动脚本所在目录，需要在那里放置 `config/paper-network.properties`，或使用上述绝对路径参数。

- 官方文档：https://info.arxiv.org/help/api/user-manual.html
- 使用要求：https://info.arxiv.org/help/api/tou.html
- 检索需要访问 `https://export.arxiv.org/api/query`，全文需要访问 `https://arxiv.org/pdf/…`。
- 包含预印本，不代表论文均经过同行评审。结果及全文均来自真实来源，不用模拟内容替代失败请求。
- 搜索在后台运行；进程内串行请求至少间隔 3.1 秒，缓存最近 30 次成功查询。多台客户端共同使用时仍需遵守来源的整体请求限制。
- 连接超时 15 秒，单次读取超时 30 秒；正文读取另有总时限。失败可重试，保留上次成功结果。
- PDF 最大 40 MiB，过大文件可通过浏览器访问。只在客户端内存保留最近一篇 PDF；用户选择下载才写入指定位置，不在服务器收集或分发全文。
- 验收前应在现场网络测试搜索与下载。开发环境直连超时，配置本地 Clash HTTP 代理后已成功下载并解析 15 页真实 PDF；官方示例检索请求返回 200，而完整分页检索曾返回 HTTP 429（来源限流），需要稍后重试，不能将其误判为网络断开。

## 验证

- `VCampusClient/tests/service/PaperSearchServiceTest.java`：Atom 数据解析、分页总数、多作者、缺失 PDF、空结果、非法 XML；传入 `live` 可测试真实检索与全文，传入 `pdf` 可单独测试真实 PDF 下载及 PDFBox 解析。
- `VCampusClient/tests/controller/PaperSearchFXMLTest.java`：真实 FXML 控件绑定、选择状态、空关键词，以及 860/1280 像素离屏布局截图。
- JavaFX 图形测试需要 SDK 原生库目录，例如启动参数 `-Djava.library.path=D:\java\javafx-25.0.4\javafx-sdk-25.0.4\bin`。
