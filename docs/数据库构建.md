# 数据库构建

## Windows 一键执行（MySQL 8 + Python 3）

在项目根目录双击 `setup-database.bat`，或者在 PowerShell 运行：

```powershell
python scripts/setup-database.py --demo
```

连接信息读取 `VCampusServer/src/resources/db.properties`；`mysql`、`mysqldump`、`python` 需要在 PATH 中。
脚本在修改已有数据库前将完整备份保存到 `.codex-tmp/database-backups/`。
首次建库执行 `init.sql`，已有基础库保留原数据；随后按文件名顺序执行 V001–V007、v101、v201。
`--demo` 只在课程表为空时导入课程演示数据；已有课程数据会拒绝导入，以免覆盖。
不需要演示数据时去掉 `--demo`。

`_vcampus_sql_history` 记录执行成功的文件及 SHA-256；重复运行自动跳过，已执行文件被修改时停止。
已有课程表却没有迁移记录的库需要先人工核对版本，脚本不会猜测并重跑 ALTER。
执行失败立即停止；MySQL DDL 不支持整批回滚，部分结构可能已提交，应结合备份检查后再继续。
此入口处理新库或已有完整基础表的库；不能自动修复任意旧版基础表。

## SQL 文件不能全部混在一起执行

| 文件 | 执行前提与用途 |
| --- | --- |
| `init.sql` | 基础建库和基础数据，自带 CREATE DATABASE / USE |
| `migrations/V001` 到 `V007` | 基础库之后，严格按编号执行；V003/V004 不能直接重复执行 |
| `migrations/v101_student_information_batch.sql` | 学籍批量操作回执表 |
| `migrations/v201_ai_tables.sql` | AI 表与知识库数据 |
| `seed/seed-course-demo.sql` | 课程演示数据；统一入口在所有迁移后执行 |
| `seed-course-test.sql` | 独立测试库的测试夹具，不能和演示数据混用，也不能直接重复插入 |
| `sample_library_data.sql` | 仅供图书馆相关表全空时导入；init.sql 已有 8 本书，因此通常应跳过 |

所有文件按 UTF-8 导入。迁移与课程种子不自行选库，手工执行前需要 `USE virtual_campus;`。
PowerShell 不支持 cmd 风格的 `<` 输入重定向，优先使用上述入口，避免字符集和选库问题。
不要为运行示例脚本清空当前使用中的图书馆。

例如单独查看连接情况：

```powershell
mysql --host=127.0.0.1 --port=3306 --user=root -p --default-character-set=utf8mb4 --execute="SHOW DATABASES;"
```

## 演示数据与自检

课程演示数据包括 12 门课程、16 个教学班、260 条上课记录、41 条选课记录。
演示账号可使用 `213242789`（学生）、`teacher01`（教师）、`admin3`（课程管理员），初始密码为 `123456`。
已存在账号的密码不会被课程演示脚本重置。

```sql
USE virtual_campus;
SELECT COUNT(*) FROM course;
SELECT COUNT(*) FROM course_offering;
SELECT COUNT(*) FROM course_occurrence;
SELECT COUNT(*) FROM enrollment;
SELECT * FROM _vcampus_sql_history ORDER BY filename;
```

课程时间列按 UTC 存储；转换为北京时间时加 8 小时。
测试夹具 `seed-course-test.sql` 使用独立测试账号及 `course-test-only` 密码，与演示账号不同。
