### 2.1.3 新增功能及其代码

#### （1） 前端与UI

相关代码：

- client.src.app.ClientMain.java，窗口创建，连接服务器与场景切换。
- client.src.resources.fxml.*，三个UI的fxml文件，可以通过Java FX官网下载SceneBuilder打开编辑。
- client.src.resources.css.style.css，色彩系统，规定了部分UI设计的色彩与规范，感觉是网页html里常用的内容？
- client.src.resources.image.icon.png，车南大学图标。

#### （2） 登录功能

相关代码：

- client.src.controller.LoginController.java，登录表单校验（一卡通号/密码不能为空），构造 login 请求（data 里带 cardNo / password / role 三个字段），异步发送并处理响应。
- server.src.handler.UserHandler.java 的 handleLogin，登录请求的服务端入口。
- server.src.service.UserService.java 的 login 方法，完整登录校验流程：

  1. 一卡通号、密码非空校验；
  2. 用 UID 查库（dao.UserDAO.findByUID），查不到提示"用户不存在"；
  3. 校验所选登录身份与账户角色是否一致（比如用"管理员"身份登学生号会被拒绝）；
  4. 密码校验（util.PasswordUtil，SHA-256(盐值+明文密码)，盐值是 16 字节随机数 Base64 编码后入库）；
  5. 全部通过后由 session.SessionManager 创建会话。

- server.src.util.PasswordUtil.java，密码哈希工具类。注意：库里存的是"哈希后的密码+随机盐值"，不是明文，即使数据库泄露也推不出原密码（课上讲过的加盐思想）。

#### （3） 会话管理（Token 机制）

登录成功后服务端用 UUID 生成一个 token，存进 SessionManager（本质是一个 ConcurrentHashMap<token, UserSession>，单例）。客户端把 token 存进 ClientSession，之后每次发请求 SocketClient 都会自动附带 sender（一卡通号）和 token；服务端在 getuserinfo / changepassword / updateprofile 这类操作前会先校验 token 是否有效，无效则提示"登录会话已失效"。

相关代码：

- server.src.session.SessionManager.java / UserSession.java，服务端会话表。
- client.src.session.ClientSession.java，客户端本地会话（保存用户名、角色、token、完整 User 对象）。
- client.src.network.SocketClient.java 的 sendAsync，自动附加认证信息的逻辑在这里。

#### （4） 主界面与个人信息维护

- client.src.controller.MainController.java，登录后主控制台：菜单栏显示"你好，xxx"，各子系统入口（学籍/图书馆/选课/商店/银行/医院/体育馆/宿舍）目前是占位提示"正在载入 xx 模块..."，另有"个人信息"跳转和"退出登录"。
- client.src.controller.ProfileController.java，个人信息页，侧边栏四个子面板：
  - 基本信息：从本地 ClientSession 读当前用户填充表单，可修改姓名/性别/学院/专业/电话/邮箱并保存（updateprofile 请求）；
  - 修改密码：见下节；
  - 头像：FileChooser 选择本地图片（目前只弹提示，未真正上传）；
  - 一卡通钱包：充值和账单查询目前是占位提示。
- server 侧对应 handleUpdateProfile → UserService.updateProfile → UserDAO.updateProfile（UPDATE tbl_user）。

#### （5） 修改密码

前端做基础校验：两次输入一致、新密码不少于 6 位。服务端流程：验证原密码正确 → 重新生成随机盐 → 用新盐哈希新密码 → 写回数据库。这样即使改密码，盐值也是新的，不会复用旧盐。

相关代码：client.src.controller.ProfileController.java 的 handleChangePassword；server 侧 UserHandler.handleChangePassword、UserService.changePassword、UserDAO.updatePassword。

#### （6） 退出登录

客户端发送 logout 请求让服务端删除会话（SessionManager.removeSession），同时清空本地 ClientSession，切回登录页。相关代码：MainController.handleLogout、UserHandler.handleLogout。
