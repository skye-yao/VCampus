# 图书在线预览与下载

已在“图书检索 → 图书详情与评价”增加在线预览、下载图书按钮。登录的学生、教师和管理员都可使用，不要求先借阅实体书。

## 配置电子书

1. 在服务端的运行工作目录下新建 `library-files` 文件夹。
2. 按数据库中的图书编号命名 PDF，例如编号 12 对应 `library-files/12.pdf`。编号可在图书检索列表查看，不能使用 ISBN 代替。
3. 重新编译客户端和服务端并启动。放入或更换 PDF 无需重启服务端。
4. 登录客户端，选中对应图书，点击在线预览或下载图书。

也可以给服务端 JVM 配置绝对路径，例如 `-Dvcampus.library.files=D:/VCampusData/ebooks`。相对路径以服务端启动时的工作目录为准。当前通过服务端文件配置电子书，未增加管理员上传界面，不需要改数据库。

## 实现方式

- `LibraryHandler` 新增 `getbookfile` 操作，复用已有 Session 校验，并确认数据库中存在该图书。
- `BookFileService` 只允许按正整数图书编号读取指定目录中的 PDF，检查真实路径及 PDF 文件头，不限制文件大小。
- 文件经 Base64 编码，通过现有 JSON/Socket 协议传输；客户端服务异步解码。
- `BookPreview` 使用项目已有 PDFBox 渲染当前页，提供上一页、下一页和页码。PDF 在后台解析，窗口关闭后忽略渲染结果。
- 下载使用系统保存对话框，在后台先写临时文件，写完再替换目标文件，失败时清理临时文件。

## 当前范围

支持任意大小的 PDF，电子版缺失时明确提示。预览会先获取整份 PDF 到内存，再逐页渲染；不是服务端分页流式阅读，因此超大文件可能占用较多客户端内存。损坏或加密的 PDF 会提示预览失败。本次未添加 TXT、EPUB 或管理员上传。

## 验收步骤

1. 为一个真实图书编号配置多页 PDF，验证预览首页、上一页、下一页及首尾页按钮状态。
2. 下载后与服务器原文件比较 SHA-256，确认一致；取消保存对话框不应发起下载。
3. 选择未配置电子版的图书，应提示暂未提供 PDF；放置非 PDF 文件，应明确拒绝，文件大小不再限制。
4. 未登录请求 `getbookfile` 应返回未授权，不存在的图书编号应返回不存在。
5. 获取文件期间切换选中图书，完成后仍应打开最初请求的图书。

已对改动的 Java 类完成编译检查，并对文件读取边界及 PDF 渲染进行自动检查；真实登录、数据库联调和图形界面操作需要启动应用后按上述步骤验收。
