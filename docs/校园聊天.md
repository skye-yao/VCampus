# 校园聊天

主界面左下角“安全退出”上方为聊天入口，括号显示未读消息与待处理好友申请总数。学生、教师、管理员均可使用。

## 部署

重新编译公共模块、服务端和客户端，重启服务端，再重新登录客户端。服务端第一次收到已登录用户的聊天请求时执行 `VCampusServer/src/resources/migrations/v301_chat.sql`，只创建不存在的聊天表。如果运行账号没有建表权限，由数据库管理员先在 `virtual_campus` 中执行该脚本。脚本可重复运行，不清空数据。

## 使用与双端验收

1. 两个客户端连接同一个服务端，分别登录不同账号，例如 `213242789` 和 `213242790`。
2. 左下角打开聊天，在“添加好友”按姓名或一卡通号查找，点击“申请好友”。
3. 对方在“好友申请”同意或拒绝。只有同意后才会出现在双方的好友列表中并允许文字私聊。
4. 选择好友发送文字，单条最多 2000 字，支持 Ctrl+Enter。会话自动同步间隔为 3 秒。
5. 对方退出登录后发送消息，对方再次登录可看到未读数及历史消息。打开并聚焦聊天窗口、选中对应好友后标为已读。
6. 超过 50 条历史消息时使用“加载更早消息”。发送失败保留草稿；相同草稿重试使用相同消息标识避免重复入库。

本版不提供群聊、附件、好友删除或撤回。消息时间由服务端存储为 UTC，界面转为当前电脑时区。用户只能访问自己的好友关系和双方消息，发送者由登录会话确定。

## 测试

`VCampusServer/tests/service/ChatServiceTest.java` 使用连接级临时表及 alice、bob、eve 测试账号，覆盖同意/拒绝、越权访问、重复发送、离线未读和历史分页，不向业务数据库持久写入测试消息。供队友手工导入的数据在 `VCampusServer/src/resources/sample_chat_data.sql`。
