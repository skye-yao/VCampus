# 图书借还、挂失与缴费

管理员的图书状态下拉栏仍只允许“遗失 → 可借（找回入库）”；其他不同状态之间的转换一律拒绝。保持状态不变可修改书名、书价等信息。借书、还书必须使用“借还与缴费”模块办理。

## 业务规则

- 学生线上预约；管理员在“预约待借”核对到场学生、图书后点击借书，预约变为已借阅，图书变为已借，生成从办理时刻起14×24小时的借阅记录。
- 管理员在“借阅未还”收到实体书后点击还书，记录归还时间、结束借阅、解除挂失、恢复可借。允许先还后缴，不会因欠费拒绝归还。
- 逾期每天0.50元，不足一天按一天计；恰好到期不收费。逾期状态每分钟自动刷新，查询时也重新核算。
- 借出前必须录入正数书价；借出时保存价格快照，后续调整馆藏价格不会追溯修改这次借阅的赔偿价。旧借阅没有价格快照时，首次核算采用管理员录入的书价。
- 首次挂失时冻结逾期计费终点。挂失不会暂停借期，逾期后同时显示“挂失中 / 逾期”，但费用不再增加；该借阅即使解除挂失，也保留已冻结的费用。找到并交回只收冻结的逾期费，没找到可选择支付书价加冻结逾期费，结清后借阅变为“遗失已赔偿”，图书仍为遗失。
- 普通未归还借阅显示动态待结算金额，归还后支付；挂失可立即选择赔偿结清。历史手工未缴罚款也可通过银行缴纳。
- 已赔偿图书后来找回，管理员找回入库结束挂失，保留原实付记录，再由管理员办理退款；不自动退款，不把赔偿当成实际归还。

## 银行支付与退款

学生缴费输入校园银行的6位支付密码。从学生银行账户扣款，进入校园财务账户（沿用银行模块的 `admin` 财务账号）；双方流水分别记录图书馆缴费和收入，用户资料余额镜像同步更新。支付金额变化时要求重新确认，不用旧金额直接扣款。

管理员可以从“借还与缴费 / 罚款缴费 / 退款”或图书馆缴费页的“管理员退款”进入，选择一条银行实付记录，填写退款金额、收款用户账号、当前管理员用户名及**管理员登录密码**。服务端核验管理员身份、账单所属用户和累计退款上限。退款由财务账户退至原用户账户，双方均有银行流水，账单保留实付金额和累计退款金额。旧版仅标记已缴而无银行交易号的记录不能直接退款。

图书、借阅、账单、银行余额及流水的每次业务变动使用同一个数据库事务。重复支付不重复扣款，相同退款请求编号不重复退款，错误密码、余额不足或流水写入失败会回滚。图书行锁串行化管理员借还、用户挂失及付款；不能通过过期请求重新打开已经结束的借阅。

## 部署与测试数据

重新编译并重启服务端和客户端。`LibrarySchema` 在启动维护任务或首次图书馆请求中，仅为现有表补充必要字段及索引，不创建数据库、不会覆盖旧业务记录。不需要重新运行整份 `init.sql`。

手工数据继续放在 `VCampusServer/src/resources/sample_library_data.sql` 原文件末尾。先启动新服务端完成字段升级，再只选中 `BEGIN LIBRARY RECOVERY TEST DATA` 起的末尾段执行。默认关联学生 `213242789`，可改为实际已有学生账号。每次执行新增5本测试图书，使用自动编号和独立ISBN，末尾注释包含借出、还书、挂失冻结、赔偿和退款步骤，不新建用户或数据库。

其他已打开客户端通过切换标签页或手动刷新获取最新数据，跨客户端没有实时推送。

## 自动验证

在仓库根目录的 PowerShell 执行。客户端和服务端有同名网络类，需要分别编译：

```powershell
$commonSources = @(Get-ChildItem VCampusCommon/src -Recurse -Filter '*.java' | ForEach-Object { $_.FullName })
$serverSources = @(Get-ChildItem VCampusServer/src -Recurse -Filter '*.java' | ForEach-Object { $_.FullName })
$clientSources = @(Get-ChildItem VCampusClient/src -Recurse -Filter '*.java' | ForEach-Object { $_.FullName })
javac -encoding UTF-8 -cp 'VCampusServer/lib/*' -d build-check/library-circulation/server $commonSources $serverSources VCampusServer/tests/dao/LibraryCirculationIntegrationTest.java VCampusServer/tests/dao/LibraryStatusIntegrationTest.java
javac -encoding UTF-8 -cp 'VCampusClient/lib/*' -d build-check/library-circulation/client $commonSources $clientSources
java -cp 'build-check/library-circulation/server;VCampusServer/src;VCampusServer/lib/*' dao.LibraryCirculationIntegrationTest
```

集成测试使用本地数据库配置连接 MySQL，但**只创建连接内的临时表**，关闭连接自动释放，不创建数据库、不修改持久业务表。旧 `LibraryStatusIntegrationTest` 入口转到相同测试。覆盖16种管理员状态组合、14天借期、计费边界、先还后缴、挂失冻结、价格快照、赔偿结清、找回、退款身份验证及金额上限、支付/退款幂等性、银行流水与余额、数据库异常整体回滚。
