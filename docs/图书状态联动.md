# 图书状态联动

管理员唯一允许的状态转换是 **遗失 → 可借（找回入库）**。其他 11 种不同状态之间的转换均拒绝，返回不合法提示，即使已有借阅人或预约人也不例外。服务端在持有图书行锁时读取最新有效状态并校验，客户端也提供相同提示。

找回入库在同一事务中解除有效挂失、结束当前借阅并补归还时间、取消遗留有效预约、将图书改为可借。公告随有效挂失解除而消失。借阅及挂失历史保留，旧归还时间不变。状态不变时只修改书名等基本信息，不更新任何关联记录。新上架图书只能为可借。

已借图书由借书人自行点击挂失；管理员不能代为将已借改成遗失。保留原有用户本人解除挂失功能。管理员找回入库后，旧的用户挂失或解除请求不能重新把书改成遗失或已借。罚款不在此操作中修改。

切换图书馆标签页会重新查询列表、个人记录和公告；用户挂失或解除后同步刷新检索列表。刷新使用请求版本，防止旧响应覆盖新结果。其他已打开客户端通过切换标签页或手动刷新获取更新，目前没有跨客户端实时推送。

## 手工测试数据

在原有 `VCampusServer/src/resources/sample_library_data.sql` 中，选中末尾 `BEGIN LIBRARY RECOVERY TEST DATA` 开始的找回入库测试数据段执行；上方原始样例仍仅用于空白图书馆。默认关联已有学生 `213242789`，可修改脚本开头的 `@recovery_test_user` 为实际登录学生账号。脚本不新建用户，不修改账号密码，不删除现有数据；账号不存在或不是学生会拒绝导入。

每次执行新增 5 本带 `[找回测试]` 前缀的图书：A/B 为未逾期及逾期的挂失书，C 为供学生自行挂失的已借书，D/E 为预约中及可借的非法转换对照书。时间相对执行日期生成，编号自动分配，ISBN 带独立批次，测试数据用完可再次执行。具体测试步骤在 SQL 文件末尾。

## 验证

项目没有 Maven/Gradle 构建文件。客户端和服务端含同名网络类，需要分别编译。以下命令在仓库根目录 PowerShell 执行：

```powershell
$commonSources = @(Get-ChildItem VCampusCommon/src -Recurse -Filter '*.java' | ForEach-Object { $_.FullName })
$serverSources = @(Get-ChildItem VCampusServer/src -Recurse -Filter '*.java' | ForEach-Object { $_.FullName })
$clientSources = @(Get-ChildItem VCampusClient/src -Recurse -Filter '*.java' | ForEach-Object { $_.FullName })
javac -encoding UTF-8 -cp 'VCampusServer/lib/*' -d build-check/library-status/server $commonSources $serverSources
javac -encoding UTF-8 -cp 'VCampusClient/lib/*' -d build-check/library-status/client $commonSources $clientSources
javac -encoding UTF-8 -cp 'build-check/library-status/server;VCampusServer/lib/*' -d build-check/library-status/server VCampusServer/tests/dao/LibraryStatusIntegrationTest.java
java -cp 'build-check/library-status/server;VCampusServer/src;VCampusServer/lib/*' dao.LibraryStatusIntegrationTest
```

集成测试使用本地 `resources/db.properties` 连接 MySQL，需要创建数据库权限。测试创建随机命名的 `vcampus_status_test_…` 独立数据库并在结束时删除，不修改应用业务表。覆盖全部 16 种状态组合（11 种拒绝、4 种仅改信息、1 种找回入库）、公告查询、保留历史和逾期状态、重复及越权挂失、旧请求、并发解除挂失与归还、数据库异常时整体回滚。
